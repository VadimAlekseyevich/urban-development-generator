# Модель данных

Система разделяет исходные datasets, нормализованные пространственные объекты и результаты конкретных запусков генерации. Каждый запуск воспроизводим через `seed`, JSON-конфигурацию, версии входных наборов и версию кода.

## Project
Контейнер исследования: название, описание, граница территории и `working_crs`. `AUTO` означает выбор локальной метрической проекции после появления границы.

## Dataset
Регистр загруженных источников: тип слоя, происхождение, исходный CRS, рабочий CRS, путь к сырому файлу, статус нормализации и metadata.

## GenerationRun
Воспроизводимый вариант генерации: `seed`, параметры, статус, версия кода, время выполнения, метрики и диагностика ошибок.

## Следующие сущности

Дальнейшие миграции добавят `spatial_features`, raster metadata, унифицированные constraints, generated roads/blocks/buildings/infrastructure, stage results и artifacts экспорта. Все пространственные слои получают GiST-индексы; площади и расстояния считаются только в метрической рабочей CRS проекта.
