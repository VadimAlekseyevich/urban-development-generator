# Генератор городской застройки

**Актуальная версия ВКР — [vkr/](vkr/).** Веб-сервис процедурной генерации жилой застройки на учебном участке с учётом пространственных, инфраструктурных и демографических ограничений.

Из корня репозитория на компьютере с Python 3.10 или новее:

```sh
python vkr/app.py
```

Откройте http://127.0.0.1:8000 и нажмите «Сгенерировать». На Linux и macOS команду можно выполнить через `python3`, на Windows — через `py`. Внешних зависимостей у новой версии нет. [Как работает алгоритм и что показать на защите](vkr/README.md).

**Предыдущая GIS-система — [legacy/](legacy/).** Здесь лежит полное дерево [исходной версии](https://github.com/VadimAlekseyevich/urban-development-generator/tree/3e77e5c93ee8c8ba27e48272c189a688d8f85203), включая документацию, данные, зависимости и прежние workflows. Команды старого README выполняются из каталога `legacy`. GitHub распознаёт workflows только в корне репозитория, поэтому архивные workflows в этой структуре не запускаются. Для воспроизведения прежнего CI используйте исходный коммит.
